Fifteen-minute path

Start where strangers can succeed.

Framework toy first, product shape second. Skip private monorepos until you are contributing internals.

  1. Clone Sesame-IDAM github.com/microscaler/sesame-idam — follow its README for Kind + Tilt.
  2. Skim BRRTRouter docs Building with BRRTRouter and the microservice layout.
  3. Run the pet store In BRRTRouter: just dev-up, then curl http://localhost:8081/health.
  4. Join the maturity board Epic 12 — pick a wave story, not a parked WebSocket rabbit hole.
