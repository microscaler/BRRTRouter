# OpenAPI is the source of truth
paths:
  /pets/{id}:
    get:
      operationId: getPet
      parameters:
        - name: id
          in: path
          required: true
          schema: { type: string }

// You own the handler — gen/ stays generated
async fn get_pet(req: TypedHandlerRequest) -> HandlerResult {
    let id = req.path("id")?;
    let pet = Pets::find(&ctx.db, &id).await?;
    ok(pet)
}

Why teams look twice

Contract-first without the tax.

Spec drives the skeleton

Routes, schemas, and stubs come from OpenAPI. You write business logic in impl/; generated code stays disposable.

Small pods, serious RPS

Designed for cloud-native scale-out — evidence-led Goose baselines, not “blazing” slogans without numbers.

Fail closed by default

Auth, body limits, parameter validation, and component $ref fidelity treated as framework maturity work.

Dogfooded in public

Sesame-IDAM is the open product-shaped reference. Private suites stay off the brochure.
